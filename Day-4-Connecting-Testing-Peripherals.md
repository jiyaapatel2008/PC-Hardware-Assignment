Day 4: Connecting and Testing Peripherals

Task 1: Connect and Test a USB Webcam

1. Connect the USB webcam to an available USB port on the computer.
2. Wait for Windows to detect the webcam automatically.
3. If required, download and install the correct webcam driver.
4. Open Device Manager and check that the webcam appears under Cameras or Imaging Devices.
5. Open the Windows Camera app and allow camera permissions.
6. Capture a photo to verify that the webcam is working correctly.

Result: The webcam is connected and working properly.

Task 2: Set Up and Test a Local Printer

1. Connect the printer to the computer using a USB cable or connect it to the same network.
2. Turn on the printer and check that paper and ink or toner are available.
3. Open Windows Settings and go to Bluetooth & devices → Printers & scanners.
4. Add the printer if Windows has not detected it automatically.
5. Install the correct printer driver if required.
6. Open the printer settings and select Print Test Page.

Result: The printer is installed and successfully prints a test page.

Task 3: Resolve a Printer Not Detected Problem

1. Unplug the printer’s USB cable from the computer.
2. Open Device Manager in Windows.
3. Check for warning icons or unknown devices.
4. Reconnect the printer’s USB cable securely.
5. In Device Manager, select Action → Scan for hardware changes.
6. If the printer is still not detected, try another USB port or cable.
7. Update or reinstall the correct printer driver.
8. Print a test page to confirm that the issue is resolved.

Result: The computer detects the printer and can communicate with it.

Task 4: Fix a Webcam Not Working in Zoom

1. Check that the webcam works in the Windows Camera app.
2. Close other applications that might be using the webcam.
3. Open Windows Settings → Privacy & security → Camera.
4. Enable camera access and allow desktop apps to access the camera.
5. Open Zoom Settings → Video and select the correct webcam.
6. Check that Zoom has permission to use the camera.
7. Restart Zoom and test the video again.
8. If the problem continues, update the webcam driver and restart the computer.

Result: The webcam works in both the Windows Camera app and Zoom.
