Day 3: Peripheral Troubleshooting

Task 1: Common Issues with USB Keyboards and Mice

1. Keyboard or mouse is not responding

* Issue: The device does not respond when connected.
* Solution: Unplug it and reconnect it to another USB port.

2. Keyboard types incorrect characters

* Issue: The keyboard displays different characters than expected.
* Solution: Check the keyboard language and layout settings in Windows.

3. Mouse pointer is moving irregularly

* Issue: The mouse pointer jumps or moves slowly.
* Solution: Clean the mouse sensor and use it on a flat, non-reflective surface.

4. USB device is not recognized

* Issue: Windows displays a USB device recognition error.
* Solution: Try another USB port and restart the computer.

5. Keyboard or mouse disconnects frequently

* Issue: The device stops working intermittently.
* Solution: Update the USB drivers and check the cable for damage.

Task 2: Troubleshooting Bluetooth Headphones That Will Not Connect to a Phone

The following steps can help identify and fix Bluetooth connection problems.

1. Check battery level: Ensure the headphones have sufficient charge and are switched on.
2. Enable Bluetooth: Open the phone’s Settings and make sure Bluetooth is turned on.
3. Enter pairing mode: Put the headphones into pairing mode according to the manufacturer’s instructions. Check for a flashing indicator light or pairing announcement.
4. Check the device list: Open the phone’s Bluetooth settings and select the headphones from the available devices.
5. Disconnect other devices: If the headphones are already connected to another phone or laptop, disconnect them and try pairing again.
6. Forget and reconnect: If the headphones appear in the saved devices list but will not connect, select Forget This Device or Unpair, then pair them again.
7. Restart both devices: Restart the phone and switch the headphones off and on.
8. Check software updates: Install available phone updates and check the headphone manufacturer’s instructions for firmware updates.
9. Test the connection: Play audio and confirm that sound comes through the headphones.

Indicators to check: Headphone battery level, Bluetooth status, pairing light, connection status on the phone, and whether the headphones are connected to another device.

Conclusion: These steps help identify common Bluetooth problems and restore the connection without immediately resetting the phone.

Task 3: External Webcam Not Detected During a Zoom Call on Windows 10

Use this checklist to identify and resolve the problem.

* [ ]	Check the USB connection: Disconnect the webcam and reconnect it. Try another USB port.
* [ ]	Check camera privacy settings: Open Settings → Privacy → Camera and allow camera access.
* [ ]	Check app permissions: Ensure that desktop apps can access the camera. Zoom must be allowed to use it.
* [ ]	Check Zoom settings: Open Zoom Settings → Video and select the correct webcam from the Camera dropdown menu.
* [ ]	Check Device Manager: Open Device Manager and look under Cameras, Imaging devices or Universal Serial Bus controllers. Check for disabled devices or warning symbols.
* [ ]	Update or reinstall the driver: Use Windows Update or the webcam manufacturer’s official website to obtain the correct driver.
* [ ]	Close other camera applications: Quit other apps that may be using the webcam, then restart Zoom.
* [ ]	Test the webcam: Open the Windows Camera app to check whether the webcam works outside Zoom.

Conclusion: Checking the connection, privacy permissions, Zoom settings and drivers usually helps identify why Windows 10 cannot detect an external webcam.

Task 4: Troubleshooting an Offline Printer Using Windows Troubleshooter

If a friend’s printer shows an offline status on their Windows PC, I would follow these steps.

1. Check the power: Ensure that the printer is switched on and has no error lights or paper jams.
2. Check the connection: For a USB printer, check the cable and USB port. For a wireless printer, confirm that the printer and computer are connected to the appropriate network.
3. Open printer settings: Go to Settings → Devices → Printers & scanners.
4. Select the printer: Choose the affected printer and click Manage.
5. Run the troubleshooter: If Windows offers a printer troubleshooter, run it and follow the instructions. In Windows 10, the option may also be available under Settings → Update & Security → Troubleshoot → Additional troubleshooters.
6. Check the print queue: Open the print queue and cancel stuck jobs if necessary. Ensure that Pause Printing or Use Printer Offline is not enabled.
7. Set the default printer: If multiple printers are installed, select the correct printer as the default when appropriate.
8. Restart the devices: Restart the printer and computer, then try printing a test page.

Attention points during troubleshooting:

* Read error messages carefully and follow the recommended steps.
* Do not unplug the printer while it is performing a firmware update.
* Confirm that the correct printer is selected before printing.
* Avoid installing drivers from unknown websites.
* Check whether the printer returns to Online status and prints a test page successfully.

Conclusion: Windows troubleshooting tools, connection checks and print queue settings can help restore printer communication and return an offline printer to normal operation.
