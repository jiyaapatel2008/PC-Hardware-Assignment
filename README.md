## Introduction

## Task 1: Desktop PC Hardware Components

The main hardware components of a desktop PC are:

1. Motherboard: Connects all the hardware components.
2. CPU: Processes instructions and performs calculations.
3. RAM: Temporarily stores data used by running programs.
4. GPU: Processes graphics and helps games run smoothly.
5. HDD: Stores files and data using magnetic disks.
6. SSD: Stores data and loads applications faster.
7. PSU: Supplies electrical power to computer components.

## Task 2: HDD vs SSD Comparison

| Feature | HDD | SSD |
|---|---|---|
| Speed | Slower | Faster |
| Durability | Has moving parts | No moving parts |
| Noise | Can make noise | Silent |
| Cost | Usually cheaper per GB | Usually more expensive per GB |
| Best Use | Backups and large files | Operating system, apps and games |

Conclusion: SSDs are faster and more resistant to physical shocks. HDDs are useful for storing large amounts of data at a lower cost.

## Task 3: Functions of CPU, RAM and GPU

### CPU
The CPU is the brain of the computer. It processes instructions, calculations and game logic.

### RAM
RAM temporarily stores data required by running programs. Sufficient RAM helps games and applications run smoothly.

### GPU
The GPU renders graphics, images and visual effects. A powerful GPU can improve gaming performance and frame rates.

In games such as PUBG and FIFA, the CPU processes game logic, RAM stores active data, and the GPU renders the graphics.
